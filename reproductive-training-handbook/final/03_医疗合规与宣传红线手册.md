# 医疗合规与宣传红线手册

适用对象：市场、新媒体、直播、投放、销售/咨询、客服、渠道、摄影剪辑、数据运营  
性质：内部培训与风控参考，不构成法律意见。所有对外宣传、广告投放、直播脚本、患者案例、医生介绍、成功率数据及活动方案，均须经机构医务、伦理、市场合规、法务/院办审核，并以最终签字版本为准。

## 1. 基本原则

1. 医疗属性优先：市场、销售、客服不得把辅助生殖服务包装为普通消费品，不得以成交或转化压过医疗安全、伦理审查和知情同意。
2. 广告先审后发：凡构成医疗广告或可能被认定为医疗广告的内容，应取得并严格按照医疗广告审查证明发布，不得擅自扩展、改写、二次创作。
3. 事实、克制、可证据化：所有资质、设备、团队、技术、流程、数据表述必须可追溯、可证明、可复核。
4. 不得承诺结果：不得明示或暗示保证怀孕、保证成功、包生、包过、一次成功、指定性别、无风险等。
5. 咨询不替代诊疗：线上客服、销售、主播、运营人员只能做流程性、预约性、科普性说明，不得诊断、开药、解读个体化治疗方案或替医生作医疗判断。
6. 隐私默认最高保护：不孕不育、辅助生殖、胚胎、配子、妊娠、遗传检测等信息均按敏感健康信息管理。

## 2. 医疗广告合规原则

### 可表达内容

- 机构依法登记的名称、地址、联系方式、诊疗科目。
- 经批准的医疗技术服务范围。
- 医疗机构执业许可证、辅助生殖技术准入资质等事实性信息。
- 医生姓名、职称、执业地点、依法可公开的学术任职和专业方向。
- 一般性健康科普和就诊流程说明。

### 不得表达内容

- 含有治愈率、有效率、成功率保证或变相保证。
- 使用患者、医生、专家、科研机构、学术机构名义作推荐证明。
- 与其他机构作绝对化、贬损性或无法证实的比较。
- 使用“国家级”“顶级”“第一”“最好”“唯一”“最权威”等绝对化用语。
- 发布未经审查或超出审查证明范围的医疗广告。
- 以优惠、限时、团购、返现、贷款、分期等方式诱导患者作医疗决定。
- 将辅助生殖技术描述为轻松、无痛、无风险、无伦理限制的消费服务。

## 3. 成功率表达规范

辅助生殖成功率高度受年龄、卵巢储备、男方因素、胚胎情况、既往病史、治疗方案、实验室条件等影响。对外宣传原则上不主动突出成功率；如确需披露，应经医务、数据、伦理、法务共同确认。

成功率数据至少应同时说明：

- 指标定义：如临床妊娠率、持续妊娠率、活产率，不得混用。
- 统计周期：如某年某季度或某年度。
- 统计对象：年龄段、治疗类型、新鲜周期/冻融周期、自卵/供精等。
- 分母口径：取卵周期、移植周期、启动周期或患者人数。
- 样本量：避免小样本造成误导。
- 数据来源：内部质控数据、上报数据或公开报告。
- 限制说明：个体结果存在差异，不能据此推断个人治疗结局。

| 禁用表达 | 替代表达 |
|---|---|
| 成功率最高 | 某统计周期内，我中心按统一口径持续监测相关质量指标 |
| 一次成功 | 治疗结果因个体情况而异，需由医生评估后制定方案 |
| 保证怀孕 | 不得承诺妊娠或活产结果 |
| 包成功/不成功退款 | 辅助生殖治疗存在医学不确定性，不设置结果承诺 |
| 90%都能成 | 不使用脱离口径、样本和条件的比例表述 |
| 高龄也能轻松怀 | 高龄患者需进行个体化医学评估，风险和预后存在差异 |

## 4. 患者隐私保护

以下信息均按高敏感等级处理：

- 姓名、电话、身份证号、住址、微信号、病案号。
- 婚育史、不孕原因、检查结果、用药方案、胚胎数量与等级。
- 精子、卵子、胚胎、遗传检测、妊娠结局、新生儿信息。
- 照片、视频、声音、就诊时间、支付记录、聊天记录。
- 可组合识别身份的模糊信息，如“35岁本地教师，三次试管失败”等。

操作要求：

- 收集信息前明确目的、范围、保存期限和使用方式。
- 不在个人微信、私人手机、非授权表格中保存患者资料。
- 不把患者病历、检查单、聊天截图发到营销群、朋友圈、短视频素材群。
- 不以“已打码”为由默认可用；若仍可识别身份，应视为未脱敏。
- 患者撤回授权后，应停止相应使用并按流程处理已发布内容。
- 发生误发、泄露、账号丢失、素材外传，应立即上报，不得私下处理。

## 5. 患者案例使用规范

患者案例原则上只用于内部教学、医疗质量改进或经严格授权后的合规科普。对外宣传使用患者案例应从严控制。

必备条件：

- 取得患者单独、明确、书面授权。
- 授权范围写明使用平台、内容形式、期限、是否可二次剪辑、是否可投放广告。
- 医务部门确认案例表述医学准确。
- 法务/院办确认不构成违规推荐证明或诱导宣传。
- 对身份信息进行充分去标识化处理。
- 不展示身份证、病历号、检查单编号、胚胎编号、完整面部、新生儿可识别影像等。

禁止做法：

- “真实患者现身说法：在我院一次成功。”
- 展示患者聊天记录、报喜截图、B超单、出生证明。
- 让患者在直播间讲述治疗经历并推荐机构。
- 用“失败多年到我院成功”暗示其他机构不行。
- 未经双方授权展示夫妻、胎儿、新生儿或家属信息。

## 6. 医生专家宣传边界

可表达：

- 医生姓名、职称、执业证书范围、专业方向。
- 经核实的学术任职、论文、课题、获奖情况。
- 出诊时间、预约方式、科普讲座安排。
- 医生对疾病常识、就诊流程、风险提示的科普说明。

不得表达：

- “送子观音”“试管大神”“包成功专家”。
- “全国第一”“行业天花板”“某地最强实验室”。
- 使用医生形象作效果背书或患者招徕。
- 医生在直播中对具体患者作诊断、承诺方案或评价其他机构。
- 包装医生个人IP时弱化机构资质、伦理规范和医学风险。

## 7. 短视频、直播、图文风险

高风险场景：

- 标题党：如“试管一次成功的秘密”“高龄必看，别再浪费卵子”。
- 结果诱导：如“今天报名，成功率更高”。
- 情绪施压：如“再不做就没机会了”。
- 价格刺激：如“限时抢名额”“套餐价”“团购试管”。
- 直播问诊：主播现场判断能否做试管、适合几代试管、成功概率。
- 评论区私信承诺：客服用个人话术承诺效果或规避资质限制。
- 展示实验室、胚胎、患者病历时泄露敏感信息。
- 用AI合成患者、婴儿、医生推荐语，造成真实背书误导。

发布前检查：

- 是否构成医疗广告。
- 是否需要广告审查证明。
- 是否含有治疗效果承诺。
- 是否含有患者隐私或案例推荐。
- 是否涉及辅助生殖伦理敏感点。
- 是否由非医生提供个体化医疗建议。
- 是否使用绝对化、刺激性、焦虑营销语言。
- 是否保留脚本、审核记录、发布版本截图。

## 8. 辅助生殖伦理红线

以下内容不得宣传、承诺、引导或协助：

- 非医学需要的胎儿性别选择。
- 代孕、商业化代孕、介绍代孕资源。
- 买卖卵子、精子、胚胎，或变相交易。
- 胚胎、配子、遗传信息的商业化营销。
- 非法供卵、跨境规避监管、地下中介合作。
- 克隆人、生殖性克隆相关内容。
- 夸大三代试管为“优生优育”“定制宝宝”“筛掉所有疾病”。
- 对不符合适应证或准入条件的人群暗示可操作。
- 绕开伦理审批、知情同意、身份核验、医学适应证审查。
- 对患者作道德评判、性别偏好迎合或家庭压力诱导。

## 9. 禁用词与替代表达表

| 类型 | 禁用词/高风险词 | 保守替代表达 |
|---|---|---|
| 效果承诺 | 包成功、保证怀、一次成、稳了 | 治疗结果存在个体差异，需医生评估 |
| 成功率 | 最高成功率、行业第一、遥遥领先 | 按统一统计口径进行质量监测 |
| 绝对化 | 最好、最强、顶级、唯一、首选 | 具备相应资质/持续开展相关服务 |
| 诱导性 | 限时名额、错过后悔、最后机会 | 可通过正规预约渠道咨询就诊安排 |
| 风险淡化 | 无痛无风险、不伤身、轻松怀 | 相关检查和治疗存在适应证、禁忌证及风险 |
| 医生包装 | 送子观音、大神、神医 | 主任医师/副主任医师/专业方向 |
| 技术夸大 | 定制宝宝、筛除所有疾病 | 在医学适应证范围内进行遗传学检测 |
| 性别选择 | 包男孩、龙凤胎方案 | 禁止非医学需要的性别选择 |
| 患者背书 | 她来我院一次成功 | 不使用患者经历作效果证明 |
| 对比贬损 | 别家不行、失败都来我们这 | 不评价其他机构诊疗水平 |

## 10. 不同岗位风险清单

| 岗位 | 主要风险 | 红线要求 |
|---|---|---|
| 市场投放 | 未审广告、夸大疗效、关键词违规 | 投放前必须完成合规审核，不得擅自改标题和落地页 |
| 新媒体运营 | 标题党、案例泄露、评论区失控 | 脚本、封面、评论回复模板均需审核 |
| 短视频/直播 | 直播问诊、承诺结果、价格诱导 | 只做科普和流程说明，医疗问题引导线下就诊 |
| 销售顾问 | 逼单、承诺成功率、规避准入条件 | 不得以业绩压力影响患者医疗决策 |
| 客服/咨询 | 个体化诊疗建议、私存资料 | 只做预约、材料提醒、流程解释 |
| 医生助理 | 代医生解释方案、转发病历 | 方案解释由医生完成，资料传输走授权系统 |
| 摄影剪辑 | 拍到患者、病历、实验室敏感画面 | 拍摄前清场授权，成片逐帧检查 |
| 渠道合作 | 中介返佣、非法供卵/代孕线索 | 合作方准入、合同、话术、素材均需审查 |
| 数据/CRM | 标签滥用、敏感信息外传 | 最小权限、留痕、脱敏、定期清理 |

## 11. 审校流程建议

内容分级：

- 低风险：节假日门诊安排、地址电话、预约流程。
- 中风险：疾病科普、检查项目介绍、医生出诊信息。
- 高风险：辅助生殖技术介绍、成功率、案例、直播、广告投放、专家包装。
- 禁止发布：代孕、性别选择、买卖配子胚胎、保证成功、未经授权案例、未审医疗广告。

审核链路：

1. 发起人自查：填写内容用途、渠道、目标人群、是否投放、是否含患者信息。
2. 医学审核：确认医学表述准确、风险提示充分、无诊疗误导。
3. 伦理审核：涉及辅助生殖伦理、胚胎、配子、遗传检测、患者案例时必须审核。
4. 隐私审核：确认授权、脱敏、素材来源、保存期限。
5. 广告合规审核：判断是否构成医疗广告及是否需审查证明。
6. 法务/院办终审：高风险内容必须签字后发布。
7. 发布留档：保存脚本、图片、视频、投放页、审核意见、授权书、发布时间和链接。
8. 上线巡检：检查标题、评论、私信话术、平台自动生成标签是否偏离审核版本。
9. 下架机制：发现违规风险立即暂停投放、下架内容、截图留证并上报。

## 12. 对外统一免责声明

“本内容仅用于健康科普和就诊流程说明，不能替代医生面诊意见。辅助生殖治疗存在适应证、禁忌证、医学风险及个体差异，具体方案和预后需由医生结合检查结果综合评估。请通过正规渠道就诊咨询。”
